# Triage Labels

## Canonical Vocabulary

| Role | Label |
|------|-------|
| Needs evaluation | `needs-triage` |
| Waiting on reporter | `needs-info` |
| Ready for an AI agent | `ready-for-agent` |
| Ready for a human | `ready-for-human` |
| Will not be actioned | `wontfix` |

## Local Markdown Usage
Use the label value in the `Status` field of `.scratch/<feature-or-ticket>/triage.md`.

## Rules
- Keep labels in English to match the installed Matt Pocock skills.
- Add French explanations in the issue body when useful.
- Do not invent extra workflow states unless a future decision updates this file.
